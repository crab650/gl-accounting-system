# 會計科目類型說明

新增科目時的「類型」決定科目在報表中的位置，以及餘額通常在哪一方增加。系統資料與 API 使用英文代碼；畫面同時顯示中文名稱。

| 代碼 | 中文 | 代表意思 | 常見例子 | 正常餘額 | 主要報表 |
|---|---|---|---|---|---|
| `ASSET` | 資產 | 企業控制、可帶來經濟效益的資源 | 現金、銀行存款、設備 | 借方 | 資產負債表 |
| `LIABILITY` | 負債 | 企業因過去事項而有的現時付款或移轉資源義務 | 應付帳款、借款 | 貸方 | 資產負債表 |
| `EQUITY` | 權益 | 資產扣除負債後，歸屬於業主的剩餘權益 | 投入資本、保留盈餘 | 貸方 | 資產負債表 |
| `REVENUE` | 收入 | 銷貨或提供服務等帶來的收入，會增加本期損益 | 銷貨收入、服務收入 | 貸方 | 損益表 |
| `EXPENSE` | 費用 | 營運時耗用的資源或發生的成本，會減少本期損益 | 薪資費用、租金費用 | 借方 | 損益表 |

「借方」與「貸方」是分錄位置，不能直接解讀為入帳或出帳。例如收到客戶款項時，銀行存款通常記借方，收入通常記貸方。正常餘額方向只是一般規則，沖銷或調整後仍可能出現反向餘額。

本系統的 `REVENUE` 是用來歸類損益表收入科目；`ASSET`、`LIABILITY`、`EQUITY` 用於資產負債表。系統目前沒有期末結轉功能，資產負債表會把「未結轉損益」另列並納入權益總額。

定義參考：[IFRS Foundation《Conceptual Framework for Financial Reporting》](https://www.ifrs.org/issued-standards/list-of-standards/conceptual-framework/)。此處的例子與正常餘額方向為本系統的實務說明。
